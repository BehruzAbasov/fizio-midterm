# Fizioterapiya və TR — Midterm

401 sualdan ibarət müstəqil statik imtahan layihəsi.

- `/` — imtahan, nəticə, səhvlərin təkrarı, variant qarışdırma və birbaşa nömrə ilə keçid
- `/oyren/` — düzgün cavabı aç/gizlət, Bildim / Təkrar et, filtr, axtarış və nömrə ilə ardıcıl keçid
- `data/questions.js` — mənbə PDF-dən çıxarılan suallar və sarı işarələr əsasında cavablar
- İrəliləyiş brauzerin localStorage yaddaşında saxlanılır; bulud sinxronizasiyası aktiv deyil.

Yayımlama: Vercel-də bu repodan yeni layihə import edin. Framework seçməyə ehtiyac yoxdur (Other / statik). Root directory: `./`. Mövcud canlı layihələrə və Supabase məlumatlarına toxunulmayıb.

Düzgün cavablar dərs PDF-ində sarı vurğulanmış variantlardan götürülüb; ayrıca tibbi ekspertiza aparılmayıb.
